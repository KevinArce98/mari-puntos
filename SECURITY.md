# Política de seguridad

## Reportar una vulnerabilidad

**No abras un issue público para temas de seguridad.**

Usá el reporte privado de GitHub: pestaña **Security → Report a vulnerability**
(o https://github.com/KevinArce98/mari-puntos/security/advisories/new).

Si no podés usar esa vía, escribí a **arias9068@gmail.com** con el asunto
`[security] mari-puntos`.

### Qué incluir

- Componente afectado: app (iOS/Android), backend/API, o sitio web.
- Descripción del problema y del impacto.
- Pasos para reproducir o prueba de concepto.
- Versión, dispositivo y sistema operativo si aplica.

### Qué esperar

- Confirmación de recepción en un plazo de ~72 horas.
- Un canal privado para coordinar el arreglo y la divulgación.
- Crédito en las notas de la corrección si lo querés.

Te pedimos no divulgar públicamente el problema hasta que exista un arreglo.

## Alcance

En alcance: código de este repositorio — `mari-puntos-app`, `mari-puntos-backend`,
`mari-puntos-website`.

Fuera de alcance: servicios de terceros (Clerk, Neon, Sentry, Expo, Vercel),
que tienen sus propios programas de reporte.
